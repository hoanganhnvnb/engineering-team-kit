# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Harassment, personal attacks and
discriminatory language are not accepted in issues, pull requests, discussions or any
other project space.

To report a problem, contact the maintainer privately through GitHub
([@hoanganhnvnb](https://github.com/hoanganhnvnb)), or use the repository's private
vulnerability reporting if the issue is sensitive. Reports are handled confidentially.
The maintainer may remove content and restrict participation, following the
Contributor Covenant's enforcement guidelines.
